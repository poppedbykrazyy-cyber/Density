# Midnight Purple for Claude chat

A black and purple theme for [claude.ai](https://claude.ai), applied with the Stylus browser extension.

## Install

1. Install Stylus for [Chrome](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne) or [Firefox](https://addons.mozilla.org/firefox/addon/styl-us/).
2. Open `midnight-purple.user.css` in this folder on GitHub and click **Raw**. Stylus offers to install it; click **Install style**.
3. Reload claude.ai.

To turn it off, click the Stylus icon and untick *Midnight Purple for Claude*.

## Notes

- It overrides the color variables claude.ai is drawn from, so it themes the whole page. If Anthropic renames those variables, parts of the page may go back to the default colors.
- The Claude desktop app doesn't load browser extensions, so this theme only works in the browser.
- The Claude Code side is themed separately by the mod in `../claude-mods/midnight-purple`.
